# Assets

Screenshots for the Milling user guide go here. Match a page's placeholder to a file, then swap
the placeholder blockquote in that page for a normal Markdown image reference, e.g.:

```markdown
![Input Settings panel, collapsed](assets/input-settings-collapsed.png)
```

Suggested naming: `<page-number>-<short-slug>.png` (e.g. `01-workflow-toolbar.png`) so screenshots
stay easy to match back to the page and section they illustrate.
