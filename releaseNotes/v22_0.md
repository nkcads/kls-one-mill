# KLS OneMill — Release Notes
## Version 2.2.0

---

## Graphics Toolbar

### Overlay Toolbar Framework
A new configurable graphics-toolbar overlay renders above the 3D view, similar to Creo Parametric's Graphics Toolbar. Modules contribute toolbar elements through a dedicated provider interface instead of manipulating the toolbar widget directly. The toolbar supports eight placements (corners and edge-centers), horizontal or vertical orientation, per-module and global visibility, and an exclusive mode in which one module's controls temporarily replace all others'.

### 3D Rotation Center Toggle
The View module contributes a checkable "3D Rotation Center" action to the graphics toolbar. Toggling it sets the camera pivot to the current scene's visible center, or clears it; the toggle stays in sync when the pivot is changed another way, such as Alt+middle-click picking in the 3D view.

## Milling

### Multiple Implants on One Raw Part (Preview)
A raw part can now hold more than one implant. Adding a second implant reuses the raw
part, machine, and fixture already chosen for the first instead of selecting a new one;
an implant list lets you add, remove, and switch which implant you're currently working
on, mark one as locked (placement protected from accidental movement) or milled
(a manual status, set once it has actually been machined), and auto-suggest a free
position for the active implant on the shared blank with basic overlap/undercut
checking. Implants you're not currently editing are shown as a simple contour outline
on the raw part rather than disappearing. A raw part can also be reused for a new
session once its implants are removed, keeping its previously machined/occupied areas
in mind when placing new ones.

### Toolpath Playback Controls
Displaying a toolpath now shows a dedicated control group in the graphics toolbar: Play, Pause, Restart, a playback-speed selector (0.05×–8×), a seekable progress slider with a percentage readout, a control for how much of the preceding path stays visible behind the current position, a tool-visibility toggle, and a Close button. Displaying a new toolpath reuses the same controls rather than rebuilding them, and positions the tool at the path's start immediately, before playback begins.

### Configurable Strut Milling-Side Defaults
The mill-bone-side, mill-opposite-side, and curve-add-offset values assigned to a newly created strut are now configurable per factory-standard template instead of fixed. The Peek, Titan, and Titan-Simple templates configure both mill sides on with a 1.5 offset; other templates keep the previous defaults unless they opt in.

### Tree Context Menu Cleanup
The session tree's "Show" and "Hide" context-menu entries have been merged into a single toggle reflecting the item's current visibility, instead of two entries where only one was ever enabled. Individual toolpath entries no longer show a generic Show/Hide at all — "Show Toolpath" and the new graphics-toolbar Close button are the correct actions for those.

### Compact Input Settings & Extended Settings Panels
The Input Settings panel's session-wide fields (Region/Material/Machine/Fixture), the raw part, and the per-implant work-piece fields each collapse to a single summary line and expand on click, freeing up vertical space — the raw part group's summary shows its current dimensions, and the work-piece group's shows the implant's file name and detected base shape. Extended Settings' strut and window/offset fields are collapsible the same way, and its action buttons (Add Manual Strut, Generate EdgePlanes, Detect Holes, Remove Detected Holes) now sit together at the top of the panel instead of split across two rows further down.

### Loop Placement for Struts
A new "Loop" option next to AddManual Strut keeps the tool armed after each strut is placed, so several can be added in a row without reselecting the button each time. Cancel at any point with Esc or a middle-click.

### Raw Part Reuse Improvements
"Suggest Position" now correctly avoids the space already occupied by implants that were on a reused library raw part, instead of treating it as free. A new Reset button clears a reused plate's reference outlines if you decide not to use it after all. Saving a raw part that's already in the library now asks whether to update the existing entry (keeping its outline history) or save it as a separate new one, instead of always silently overwriting it.

### PMMA Material
PMMA is now available as a material type alongside Titan, Peek, and MultiPurpose.

## Bug Fixes

### Toolpath Animation Trail Sometimes Missing
Seeking, restarting, or changing the visible-history setting while a toolpath animation was displayed could permanently stop the path trail from being drawn for the rest of the session, while the tool actor kept moving normally. A rebuild step was shrinking the underlying draw buffer in a way that broke the incremental drawing used during normal playback; the buffer now stays at full size across every rebuild path.

### Tool Position Not Updated When Seeking
Dragging the toolpath animation's progress slider moved the drawn path trail but left the tool actor at its previous position. Seeking now repositions and re-orients the tool to match the sought position, the same as normal playback does.

### Shutdown Crash During Application Close
Closing the application could occasionally crash inside Qt's Windows platform integration during final process cleanup. A module-owned toolbar widget was only being detached — not destroyed — when its toolbar closed, leaving it to be destroyed much later during plugin unload, after Qt's platform integration could already be torn down. The widget is now destroyed explicitly and early, while the application is still fully running.

### Implant Positions Corrupted When Dragging a Different Implant
With more than one implant in a session, dragging one implant's position could, in certain cases, corrupt the stored position of a different implant that wasn't even being touched. Repositioning now always commits to the implant actually being displayed on screen, not whichever one happened to be the "active" one.

### IGES Milling Preview Not Following Implant While Dragging
The IGES milling preview elements stayed in place instead of moving with the implant during live repositioning; they now update together with it.

### Crash Selecting a Machine/Fixture With No Matching Raw Part
Selecting certain machine/fixture combinations could crash the application instead of showing an error when no matching raw part was found for them.

### Action Buttons Disabled After Swapping to a Reused Raw Part
After loading a raw part to reuse an existing plate on a session that already had implants, buttons like Assign Implant Position, Refresh, and Geometry became disabled even though the implant was still there and workable. They now stay enabled as expected.
