# KLS OneMill — Release Notes
## Version 2.0

---

## Strut Handling

### Extended Support
Struts are now fully integrated into the milling workflow. Both automatic and manual strut links are supported, with independent configuration for bone-side and opposite-side milling per strut strategy.

### Individual Strut Control
Each strut can be moved, rotated, and configured independently after placement. Per-strut milling parameters (radius, feed, depth, shape) override the global link configuration without affecting other struts.

### Strut Removal Milling
Dedicated strut removal strategies are available with material-specific presets for Peek and Titan.

---

## IGES Import

### Coordinate System Import
Coordinate systems are now extracted from IGES files and used for workpiece alignment.

### Extended Curve Import
The IGES importer now reads lines, arcs, NURBS curves, and composite curves — enabling more complete geometry import for hole definition and program generation.

---

## Edge Milling

Raw part edge planes are now detected automatically and included as a dedicated milling operation. Edge planes are saved with the session and restored on reload.

---

## Strategies

### Material Presets
Material-specific named strategy presets replace the previous generic configurations. Presets are calibrated per material and market variant (DE / US).

### Curve Strategies
Curves can be assigned individual milling strategies independent of the global geometry strategy, giving fine-grained control over feed rate, step-down, and tool selection per curve type.

---

## Factory Defaults

The factory standard system has been significantly extended:

- **Richer entry description** — entries now carry a display name and category for clearer organisation in the UI
- **Orientated milling** — factory standards support oriented sub-program strategies alongside standard cylindrical operations
- **Optional entries** — entries can be marked optional and substituted by mapping ID, allowing flexible tool assignment without breaking the standard

### Hole Drilling — Categories & Extended List

Hole factory standards are now organised into categories grouped by implant system and connection type. The list has been extended to cover additional implant systems and screw connection variants, including non-locking and countersink configurations.

---

## Milling Time Estimation

Estimated milling duration is calculated and displayed per session, shown as h:mm:ss. The estimate accounts for toolpath length, feed rates, and tool change overhead.

---

## Toolpath Preview

Strut and link toolpath preview has been improved. The milling contour for each strut is shown in real time before committing to generation.

---

## Tool Lists

Tools now carry a mapping ID that uniquely identifies them across import and export operations. This enables consistent tool substitution and traceability when tool lists are exchanged between systems.

---

## Milling Contour — I/U-Shape

Two contour generation modes are now available:

- **I-Shape** — standard inner/outer profile for implants with a closed bottom geometry
- **U-Shape** — open bottom profile for fixtures with limited access depth

---

## Post-Processor

### Hole Drilling
Full NC output for drilling operations, with feed rates, spindle speeds, and plunge/retract feeds taken from the machine configuration.

### Machine Parameters
Machine-specific parameters are loaded from the machine configuration and applied directly to NC code generation, ensuring machine values override generic defaults.

### Orientated Holes
Holes in non-standard orientations are now correctly output in the NC file, rotated into the machine coordinate system.

### Custom NC Code Blocks
Predefined NC code blocks can be inserted at defined positions in the output (e.g. machine-specific preamble sequences or macro calls), without manual post-editing.

### Heidenhain Cycle 326
Support for Heidenhain dynamic machining setup (CYCL DEF 326), enabled via machine settings.

---

## UI

### Splash Screen
A branded splash screen is shown on application startup.

### Theming & Styling
Stylesheet and icon updates across all themes (dark, light, windows, klsmartin).

### Quick Menu
Simplified quick-access toolbar for faster module switching without opening the full tool panel.
