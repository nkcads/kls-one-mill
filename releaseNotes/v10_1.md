# KLS OneMill — Release Notes
## Version 1.0.1

---

## Milling Strategy

### Gauge Check
Before generating toolpaths, the system now verifies that the selected tool fits within the milling geometry. Oversized tools are flagged early, preventing potential collisions.

---

## OpenMill

### Retract Distance
The retract distance for OpenMill operations has been adjusted to reduce unnecessary air moves and improve overall cycle time.
