# KLS OneMill — Release Notes
## Version 1.0.0

---

## 3D Viewport

- **Pan, Zoom, Rotate** — Full interactive navigation in the 3D viewport
- **Default Views** — One-click standard views: front, back, left, right, top, bottom
- **Orientation Indicator** — Persistent display of the current view orientation
- **Object Selection Highlighting** — Selected objects are highlighted in the viewport

---

## Data Import

- **STL Import** — Load 3D geometry from STL files
- **IGES Curve Import** — Read curves from IGES files for hole definition and program generation

---

## Raw Material

- **Shape Selection** — Automatic stock shape selection based on the loaded 3D model
- **Size Configuration** — Manual configuration of stock material dimensions
- **Fixture Selection** — Select the clamping fixture for the milling job
- **Model Positioning** — Interactively position and orient the model relative to the stock material

---

## Support Structures

- **Link Amount** — Define the number of milling links to generate
- **Link Position** — Place milling links at custom positions around the object
- **Milling Window Offset** — Configure the boundary area to be milled

---

## Milling Strategy

- **Material-based Selection** — Choose the milling strategy based on the workpiece material

---

## Program Generation

- **2D Contour Milling** — Generate milling programs from 2D contour geometry
- **3D Surface Milling** — Generate milling programs from 3D surface data
- **Hole Drilling** — Generate drilling programs from hole definitions
- **Toolpath Display** — Visualise the generated toolpath in the 3D viewport
- **Result Geometry** — Display the resulting geometry after each milling operation step
- **NC-Code Output** — Write machine-ready NC code for the generated program
- **Machine-specific Post-Processing** — Adapt NC output to the target milling machine

---

## Fixture

- **Fixture Generation** — Automatically generate a 3D fixture model for the implant geometry

---

## UI

- **Object Tree** — Hierarchical list of all objects in the viewport
- **Context Menu** — Right-click context menu on objects in the object tree

---

## System

- **Logging** — Event logging for usage traceability and diagnostics
