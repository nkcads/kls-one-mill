# KLS OneMill — Release Notes
## Version 1.0.0

---

## 3D Viewport

- **Pan, Zoom, Rotate** — Full interactive navigation in the 3D viewport
- **Default Views** — One-click standard views: front, back, left, right, top, bottom
- **Orientation Indicator** — Persistent display of the current view orientation
- **Object Selection Highlighting** — Selected objects are highlighted in the viewport

---

## Data Import

- **STL Import** — Load 3D geometry from STL files

---

## UI

- **Object Tree** — Hierarchical list of all objects in the viewport
- **Context Menu** — Right-click context menu on objects in the object tree

---

## System

- **Logging** — Event logging for usage traceability and diagnostics
