# KLS OneMill — Release Notes
## Version 2.1.0

---

## IGES Import

### Inner Curves
The IGES importer now reads inner curve geometry from IGES files. These curves are used directly for hole definition and milling contour generation, enabling more accurate program output for complex implant geometries.

---

## Strategy Tree

### Session Overview
A new tree view panel displays all strategy entries for the current session. Each entry shows its current state, activation status, and any active dynamic value overrides at a glance.

### Dynamic Value Overrides
Individual strategy entries can be overridden with custom dynamic values (e.g. depth, feed rate) directly from the tree panel without modifying the global strategy. Overrides are saved with the session and restored on reload.

### NoExport Entries
Strategy entries can be marked as NoExport to exclude them from NC output while keeping them visible in the session. The tree reflects the NoExport state and the post-processor respects the exclusion during code generation.

### Entry Reset
Individual entries and dynamic value overrides can be reset to their strategy defaults from the tree context menu, either per entry or for the entire session at once.

---

## Post-Processor

### Pack Drilling
Drilling operations are now grouped and packed per tool, reducing tool changes and improving overall program structure for multi-hole components.

### Dwell Times
Dwell times at drilling depth (Q211) and at top (Q210) are now always written to the NC output, including when the value is zero. This ensures machine parameters are always explicitly set and not left to controller defaults.

### Chip Break Retract
The chip break retract distance (Q256) is now always written to the NC output, including when the value is zero, consistent with the other cycle parameters.

---

## Factory Standards

### Werksnormen
Dutch market factory standard definitions (Werksnormen) have been added, covering implant-specific hole categories and milling configurations for the NL market variant.

### US Fixture Safety Area
A spline-based safety area definition for US fixture configurations has been added, providing tighter boundary control for US market fixture milling programs.
